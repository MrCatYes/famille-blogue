# Famille — blogue de développement

Blogue technique du projet [Famille](https://github.com/MrCatYes/famille), construit avec [Hugo](https://gohugo.io) et publié sur GitHub Pages à chaque push sur `main`.

Site : https://mrcatyes.github.io/famille-blogue/

## Écrire un billet

```bash
hugo new content billets/AAAA-MM-JJ-sujet.md
hugo server --buildDrafts
```

Passer `draft: false` dans l'en-tête du billet pour le publier.
